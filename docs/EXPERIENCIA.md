# Traductor de voz

Reconoce voz, traduce la transcripción y genera audio.

- Entrada: Voz desde el micrófono y configuración de idiomas.
- Resultado: Transcripción, traducción opcionalmente visible y audio.
- Tecnología: Web Speech API · Google Translate · gTTS

## Uso

Pulsa Escuchar, permite el micrófono y habla. Selecciona los idiomas y pulsa Convertir a audio.

## Límites

El reconocimiento inicial está configurado en español y depende del soporte del navegador. Requiere conexión.
